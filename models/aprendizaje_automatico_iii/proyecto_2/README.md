# Modelos · Proyecto 2

Esta carpeta reserva el espacio para un modelo final publicado explícitamente.

Pesos descargados de modelos fundacionales, checkpoints temporales, cachés y fine-tunings experimentales permanecen fuera de Git. Los experimentos locales usan
`semestre_vii.aprendizaje_automatico_iii.proyecto_2.PROJECT_MODELS_DIR` como raíz cuando sea necesario.

No se incluye todavía ningún modelo: primero se construyen los baselines, el backtesting y la comparación reproducible.
