# Modelos · Reabastecimiento de gasolineras

Espacio reservado para artefactos de modelos que el proyecto decida publicar explícitamente.

El código usa
`semestre_vii.desarrollo_de_aplicaciones.reabastecimiento_gasolineras.PROJECT_MODELS_DIR`
como raíz.

Pesos descargados, checkpoints temporales, caches, fine-tunings experimentales y resultados reconstruibles permanecen fuera de Git.

Todavía no existe un modelo final aprobado. Primero se construyen baselines y se compara cualquier candidato mediante el mismo rolling-origin backtesting.
