# Código de la entrega

La fuente canónica del servicio está en la raíz del proyecto. El paquete local `192488-7_Leon_Fernando_2P.zip` incluye en esta sección una copia ejecutable: `frontend/`, `api/`, `db/`, corpus ficticio, Compose, `.env.example`, instrucciones y README.

La copia excluye entornos, dependencias, caches, builds, credenciales y volúmenes. El paquete usa `api/` conforme a la rúbrica; la fuente del repositorio permanece en `backend/`. Compose, Dockerfile y README del paquete adaptan esos paths sin cambiar el motor. La [verificación actual A*](../07_Evidencias/c2_a_asterisco.md) registra el arranque aislado; el recibo final se conserva junto al ZIP.

La carpeta OneDrive y el correo oficial no se han compartido ni enviado.
