## Regla de autoridad

La planeación original de Traveler se usa como baseline funcional. Las decisiones técnicas más recientes que ya existían en Semestre VII se incorporan aquí cuando refinan esa planeación sin cambiar su intención.

Una afirmación pendiente de validación se mantiene explícitamente como pendiente; no se convierte en requisito por repetición.
